# Мемлерея — политика конфиденциальности

*Действует с 26 октября 2026 г.* · [English version below](#memlereya--privacy-policy)

Мемлерея (`me.oxip.memlereya`) — галерея с тегами для фото и видео из одной папки на устройстве.

## Коротко

Приложение **не собирает** никаких данных и **ничего никуда не отправляет**. У него нет доступа
к интернету: в нём нет аккаунтов, рекламы, аналитики и отчётов о сбоях.

## С чем работает приложение

- **Файлы в папке, которую вы выбрали.** Доступ только к этой папке, вы выдаёте его через
  системный диалог выбора папки. Приложение читает фото и видео из неё, чтобы показать их,
  и удаляет файл, только если вы сами нажали «Удалить».
- **Теги и сведения о файлах.** Имена файлов, ваши теги, даты, размеры и миниатюры хранятся
  во внутренней памяти приложения на устройстве.
- **Резервная копия тегов.** Приложение сохраняет теги в файл `.memlereya-tags.json` в той же
  папке, чтобы они пережили переустановку. Файл остаётся у вас на устройстве.

Всё это хранится только на вашем устройстве. Разработчик не получает ни файлов, ни тегов,
ни каких-либо других данных.

## Передача другим приложениям

Файлы уходят в другие приложения только по вашему действию: «Поделиться», «Копировать»
или выбор файла, когда другое приложение просит фото или видео. Получатель получает доступ
к одному выбранному файлу и никогда — ко всей папке.

## Удаление данных

При удалении приложения система стирает базу тегов и миниатюры. Файл `.memlereya-tags.json`
лежит в вашей папке, удалить его можно любым файловым менеджером.

## Дети

Приложение не предназначено специально для детей и ни у кого не собирает данных.

## Изменения

Если политика изменится, новая версия появится на этой странице с новой датой.

# Memlereya — Privacy Policy

*Effective October 26, 2026*

Memlereya (`me.oxip.memlereya`) is a tag-based gallery for photos and videos in a single folder
on your device.

## In short

The app **does not collect** any data and **does not send anything anywhere**. It has no internet
access: no accounts, no ads, no analytics, no crash reporting.

## What the app works with

- **Files in the folder you choose.** Access is limited to that folder, granted by you through
  the system folder picker. The app reads photos and videos there to display them, and deletes
  a file only when you tap "Delete".
- **Tags and file details.** File names, your tags, dates, sizes and thumbnails are stored in the
  app's private storage on your device.
- **Tag backup.** The app saves your tags to a `.memlereya-tags.json` file in the same folder so
  they survive a reinstall. The file stays on your device.

All of this stays on your device. The developer receives no files, tags or any other data.

## Sharing with other apps

Files reach other apps only through your own action: "Share", "Copy", or picking a file when
another app asks for a photo or video. The receiving app gets access to that one file, never
to the whole folder.

## Deleting your data

Uninstalling the app makes the system erase the tag database and thumbnails. The
`.memlereya-tags.json` file is in your folder; you can delete it with any file manager.

## Children

The app is not specifically directed at children and collects no data from anyone.

## Changes

If this policy changes, the new version will be posted on this page with a new date.
